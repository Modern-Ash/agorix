# User Stories — issue-91

- US-001: As a learner, I complete a full browser journey through First Mission that passes deterministically.
- US-002: As a learner, I make at least one explicit decision before any AI proposal is applied to my program.
- US-003: As a learner, when I debug, the debugger cites/uses actual runtime facts rather than model claims.
- US-004: As a learner, I see step-by-step execution highlighting as my program runs.
- US-005: As a learner, I capture my reasoning in a reflection step, without it gating mission completion.
- US-006: As a product owner, I need a test that fails if AI can bypass the acceptance flow.
- US-007: As a stakeholder, I have artifacts/screenshots that demonstrate the AI-native product differentiator.
- US-008: As a tablet learner, the full journey passes in tablet landscape orientation.
- US-009: As a tablet learner, the critical journey passes in tablet portrait orientation.
- US-010: As a learner, I am not required to use a permanent Scratch-style toolbox.
- US-011: As a learner, World and Code remain the dominant surfaces of the experience.
- US-012: As a learner, my interaction state survives orientation/viewport changes.
