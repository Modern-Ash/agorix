# User Stories — issue-99

- US-001: As a learner, I can tell a change is only proposed (not yet applied) vs already accepted into my program.
- US-002: As a learner, I can tell a message is a real runtime result vs an AI suggestion.
- US-003: As a learner, I'm reminded AI can be wrong without alarming language.
- US-004: As a learner with color-vision differences, I can still tell states apart (icon+text, not color alone).
- US-005: As a screen-reader user, the same distinction reaches me via aria-label.
- US-006: As a learner, I never see a provider/vendor name presented as an authority.
- US-007: As a tablet learner, proposal state is understandable without jargon.
- US-008 (deferred): As an Agorix Studio user, I can optionally see technical diagnostics.
- US-009: As a learner on either implemented surface, the same suggestion-vs-fact distinction holds.
