# User Stories

- US-001: As a learner on a landscape tablet, I can see the World and generated Code as the main learning surfaces without a toolbox consuming the left side.
- US-002: As a learner on a portrait tablet, I can scroll from mission to World to Code to actions without Code being hidden in a tab.
- US-003: As a learner, I can add blocks from a contextual action palette using touch or keyboard.
- US-004: As a learner, I can run, stop and reset my program with controls that are large enough for touch and reachable from the keyboard.
- US-005: As a learner, I can rotate the tablet and keep my current blocks, generated code and run state context.
- US-006: As a learner asking for help, I see Learning Companion guidance near the work without losing sight of Code.
- US-007: As a reviewer, I can run Playwright tests that explicitly prove tablet landscape and portrait behavior.
- US-008: As a Spanish-language learner, longer labels continue to fit without clipping critical controls.
