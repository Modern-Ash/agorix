# Intent interpretation

Deliver GitHub issue #118 by replacing the current desktop-editor-first web shell with a tablet-first learning surface where World and Code are the dominant persistent surfaces.

The work is a brownfield UI architecture change for `apps/web`. It must preserve the existing canonical program, runtime, i18n, persistence and Learning Companion behavior while changing the shell hierarchy and responsive behavior.

## Source facts

- Source issue: https://github.com/Modern-Ash/agorix/issues/118
- Parent epic: #116.
- Required dependency already delivered: #117 design system.
- Additional referenced sources: #74 UX contract, #110 localization requirements, `docs/product/DESIGN_SYSTEM.md`, `docs/product/UX_REQUIREMENTS.md`, `AGENTS.md`.
- Tablet landscape and portrait are primary targets, not smoke-test afterthoughts.
- Code must remain visible and inspectable in normal flow; it must not move behind an advanced tab.
- Learning Companion and action insertion must become contextual, not permanent dominant panels.

## Product intent

The learner should open Agorix on a tablet and immediately see:

1. The mission/progress as compact chrome.
2. The World where runtime behavior is visible.
3. The Code that reflects the canonical program.
4. Touch-friendly run/step/stop/reset controls.
5. Contextual actions and Learning Companion help that support the work without taking over the screen.

## Out of scope

- Replacing Blockly/editor model internals.
- Introducing a new mission or runtime behavior.
- Adding provider-backed AI behavior.
- Redesigning Agorix Studio.
- Formal accessibility certification beyond the issue's checkable UX requirements.
