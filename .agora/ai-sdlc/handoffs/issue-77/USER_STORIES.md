# User Stories - issue #77

- As a learner, I can see what changed before and after each instruction without reading internal logs.
- As a tablet learner, I can read a short beginner trace such as movement direction and x/y change.
- As a Studio user, I can inspect richer state values and canonical node ids.
- As a learner, I can correlate each trace item to the highlighted block and code range.
- As a guardian/school, I can trust that the trace is deterministic and contains no PII/provider data.
