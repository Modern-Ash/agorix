# Non-functional Requirements - issue #77

- Trace facts must derive solely from deterministic runtime observations and execution steps.
- Beginner trace must avoid stack traces, provider names, prompts and irrelevant engine internals.
- Presentation profiles must be localizable through existing i18n/catalog patterns.
- Studio and Web must share canonical node ids even when presentation differs.
- Tests must prove ordering, before/after values and privacy constraints.
