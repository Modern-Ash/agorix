# Issue 100 User Stories

- As a learner, I see a safe/plain message when AI output is rejected, and my program does not silently change.
- As a developer, I get actionable non-PII diagnostics for rejected provider output.
- As a maintainer, I can run adversarial validation tests without real provider credentials or network calls.
- As a provider adapter author, I must return structured output that passes the same validator as every other adapter.
- As a Product Owner, I can verify that child-safety constraints override AI convenience.
