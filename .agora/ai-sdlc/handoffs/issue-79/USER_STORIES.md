# User Stories - issue #79

- As a learner, I can trust that every language view is generated from the same canonical program.
- As a UI implementer, I can ask a projection for text and canonical node ranges without depending on a specific language.
- As a future language-pack author, I can implement a projection contract and prove conformance with reusable tests.
- As a maintainer, I can detect unsupported canonical nodes explicitly instead of silently rendering partial or misleading code.
- As a product/architecture reviewer, I can see how the existing TypeScript-like generator migrates without changing semantics.
