# Issue 95 User Stories

- As a developer, I can configure a commercial remote provider on the server without changing domain code or browser code.
- As a maintainer, I can run the test suite without commercial credentials or network access.
- As a curriculum/runtime owner, I can trust that remote provider output is validated before it can become a program proposal.
- As an operator, I can fall back to fake/local/offline behavior when a remote provider is unavailable.
- As a future adapter author, I can follow documented contract guidance to add another commercial provider.
