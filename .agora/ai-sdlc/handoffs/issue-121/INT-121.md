# Intent interpretation

Issue #121 makes cross-surface compatibility a testable invariant: Web-created projects must open in Agorix Studio, Studio-modified canonical projects must reopen in Web, and semantic equivalence must survive the round trip.

## Source facts

- Parent epic: #116.
- #38 added the Studio first slice and explicitly handed full Web/Studio round-trip proof to #121.
- Shared persistence uses `StoredProject` with `schemaVersion`, `program` and `metadata`.
- Locale and selected projection are presentation/user preferences, not hidden canonical semantics.

## Proposed interpretation

- Add a cross-surface compatibility contract as durable product/architecture source of truth.
- Add deterministic fixture(s) and automated tests that exercise Web-like storage, Studio open/modify, Web reopen and semantic hash/equivalence.
- Keep UI state out of canonical program and fail newer schemas explicitly through existing persistence errors.
