# User Stories

- As a learner, I want a project started on tablet to open in Studio without changing what my program means.
- As a learner, I want a Studio-approved change to reopen in Web as the same accepted canonical program.
- As a reviewer, I want a semantic hash proving that presentation state and locale preferences did not change program semantics.
- As an engineer, I want unsupported newer schema versions to fail explicitly instead of being misread.
