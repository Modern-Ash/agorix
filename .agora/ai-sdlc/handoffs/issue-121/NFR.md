# Non-functional Requirements

- NFR1: Compatibility tests must be deterministic and credential-free.
- NFR2: Semantic hashing must ignore presentation-only state.
- NFR3: Canonical program validation remains the authority for project semantics.
- NFR4: No UI-specific IDs may enter `ProjectProgram`.
- NFR5: Fixture data must not include child PII, provider credentials or environment-specific paths.
