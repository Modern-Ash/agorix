# User Stories

## Learner

- As a learner, I want missions to feel like places with objectives and feedback so that
  programming feels purposeful.
- As a learner, I want the same program behavior to remain true even when the world theme changes
  so that visuals do not hide the programming concept.
- As a learner using reduced motion, I want the world to preserve functional feedback without
  unnecessary animation.

## Product / curriculum author

- As a curriculum author, I want to associate a mission with one or more world themes without
  rewriting runtime logic.
- As a curriculum author, I want localized world copy and assets without changing mission IDs or
  completion predicates.

## Engineer

- As an engineer, I want a contract that Web and Studio can both render so that cross-surface
  project compatibility remains intact.
- As an engineer, I want asset licensing rules so that future content can be shipped safely.
