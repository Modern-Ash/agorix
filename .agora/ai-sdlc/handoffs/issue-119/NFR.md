# Non-functional Requirements

- NFR1: Worlds must preserve deterministic runtime behavior and canonical program authority.
- NFR2: Worlds must be platform-neutral enough for Web and Studio preview renderers.
- NFR3: World visuals must be accessible: non-color-only feedback, keyboard-compatible UI around
  the world and reduced-motion alternatives.
- NFR4: World content must be localizable without structural divergence.
- NFR5: Asset requirements must support open-source-first distribution and future replacement.
- NFR6: Product chrome must remain calm; expressive styling belongs primarily inside the World
  surface.
