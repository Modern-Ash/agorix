# Risk Register

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Worlds becomes a hidden second runtime model | High | Define Worlds as theme/content over mission and runtime contracts only. |
| Mission IDs drift by locale or theme | High | Require stable IDs; localize display content only. |
| World-specific assets imply world-specific logic | Medium | Require generic domain capabilities before runtime expansion. |
| Product chrome becomes game UI | Medium | Keep expressive visuals inside World surface; preserve calm shell. |
| Reduced-motion mode loses functional feedback | Medium | Require static state changes and non-motion feedback. |
| Asset provenance is unclear | Medium | Document license, source and attribution requirements up front. |
| Studio preview diverges from Web semantics | High | Define shared render inputs and require mission/runtime parity. |
