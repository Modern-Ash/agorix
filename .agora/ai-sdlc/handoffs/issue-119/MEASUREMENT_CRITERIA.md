# Measurement Criteria

- MC1: `docs/product/WORLDS.md` states that worlds do not change canonical program schema.
- MC2: The document defines locale-independent mission IDs and localized display content.
- MC3: The document defines world asset/theme variation without logic forks.
- MC4: The document maps mission semantics to Web and Studio World Preview render needs.
- MC5: The starter world includes reduced-motion behavior.
- MC6: The document includes asset source, license and attribution rules.
- MC7: Repository checks pass after adding the product source of truth.
