# Proposed Units

## UOW-119-01: Worlds Architecture Source of Truth

Define `docs/product/WORLDS.md` and validate it against the current architecture, curriculum and
interaction model.

### Why one unit

#119 is a bounded documentation/pathway issue. Splitting into multiple executable units would add
governance overhead without improving review boundaries.

### Deliverables

- Worlds product model.
- World/theme contract.
- Asset/theme boundary.
- Mission-to-world association.
- Progression rules.
- Starter world specification.
- Acceptance trace.
