# Measurement Criteria

- MC1: `pnpm build` includes `extensions/vscode` or an explicit extension build command.
- MC2: Tests load a Web-compatible stored project fixture through shared project contracts.
- MC3: Tests assert active canonical node maps to a textual projection range.
- MC4: Tests assert step/run evidence drives both preview frame data and inspector data from the
  same runtime observations.
- MC5: Tests assert ProgramProposal reject does not mutate accepted canonical program state.
- MC6: Tests or fixtures show explicit apply is required before accepted state changes.
- MC7: Documentation identifies the #121 handoff for Studio-modified fixture reopening in Web.
- MC8: Documentation traces Studio visual language to #117 and Worlds preview to #119.
