# Non-functional Requirements

- NFR1: Shared domain packages must remain free of VS Code API imports.
- NFR2: Studio tests must run in local CI without provider credentials.
- NFR3: The first slice must be small enough to review independently.
- NFR4: Studio should use IDE-density UI while preserving #117 design semantics.
- NFR5: ProgramProposal operations must be auditable and explicit.
- NFR6: Project fixtures must be deterministic and free of child PII/secrets.
- NFR7: Studio must degrade without remote AI provider availability.
