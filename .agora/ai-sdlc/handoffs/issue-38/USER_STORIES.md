# User Stories

## Learner

- As an advanced learner, I want to open my Agorix project in Studio so I can inspect code-like
  projections without losing my program.
- As a learner, I want Step to update code, preview and evidence together so I can debug behavior.
- As a learner, I want AI proposals to appear as reviewable diffs/suggestions so I can decide
  before anything changes.

## Educator / reviewer

- As an educator, I want Studio to preserve Web mission semantics so progression between surfaces is
  safe.
- As a reviewer, I want fixtures proving Studio uses shared contracts so #121 can validate the full
  round trip.

## Engineer

- As an engineer, I want VS Code API usage isolated so shared packages stay platform-neutral.
- As an engineer, I want extension logic testable without launching VS Code wherever possible.
