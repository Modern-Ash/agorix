# Suggested Bolts

## Bolt 1: Interaction Contract

- Produce the durable interaction model.
- Trace each required interaction and accessibility requirement.
- Identify what is implemented now versus future-compatible stylus opportunities.

Depends on: approved inception.

## Bolt 2: Touch/no-drag Web Affordances

- Strengthen Action Palette and block-card affordances.
- Ensure non-drag add/remove/reorder/numeric editing remains clear and reachable.
- Preserve World + Code context.

Depends on: Bolt 1.

## Bolt 3: Responsive Input Safety

- Verify orientation state preservation.
- Verify virtual-keyboard-safe numeric input behavior.
- Verify EN/ES labels do not hide critical controls.

Depends on: Bolt 2.

## Bolt 4: Verification and PR

- Add/adjust Playwright and unit tests.
- Run format, test, build and e2e verification.
- Register evidence and open PR.

Depends on: Bolt 3.
