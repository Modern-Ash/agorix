# User Stories

- US-001: As a tablet learner, I can add Move/Turn/Repeat/If from the Action Palette by tapping.
- US-002: As a tablet learner, I can complete the First Mission without dragging any block.
- US-003: As a learner, I can reorder blocks using explicit controls instead of drag.
- US-004: As a learner, I can edit numeric block values on a tablet without losing access to the relevant program context.
- US-005: As a learner, I can rotate the device while editing and keep my current blocks and generated code.
- US-006: As a keyboard user, I can add, remove and reorder blocks without pointer-only interaction.
- US-007: As a Spanish-language learner, the same interaction path works with Spanish labels.
- US-008: As a reviewer, I can run automated tests that prove the key touch/no-drag paths.
- US-009: As a future stylus user, I am not required to use a stylus, but the model documents where stylus could later add intent/path input.
