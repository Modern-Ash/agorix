# Non-functional Requirements

- NFR-001 Accessibility: all critical edit actions must have keyboard-accessible and non-drag alternatives.
- NFR-002 Touch targets: primary edit controls and action buttons must meet at least 44x44 CSS px.
- NFR-003 Input resilience: numeric input must support mobile virtual-keyboard conditions without hiding essential commit/cancel or context controls.
- NFR-004 Localization: English and Spanish labels must wrap or reflow without breaking key controls.
- NFR-005 State continuity: orientation changes must preserve canonical program and generated code.
- NFR-006 Visual clarity: nested/ordered structures must read as manipulable cards, not Scratch-like puzzle pieces as brand identity.
- NFR-007 Privacy/safety: no provider credentials, child PII or production identifiers are introduced.
