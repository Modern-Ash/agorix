# User stories

## US-069-01 - Child learner keeps authorship

As a child learner, I want AI suggestions to stay visible as suggestions until I decide what to use, so that the program remains mine.

## US-069-02 - Learner understands behavior through evidence

As a child learner, I want to predict, run and observe my program, so that I can connect blocks and code to what actually happened.

## US-069-03 - Learner debugs with facts

As a child learner, I want the system and AI to use runtime evidence when helping me debug, so that mistakes become learning material instead of hidden fixes.

## US-069-04 - Reviewer understands the product difference

As a product or pedagogy reviewer, I want the source docs to explain how Agorix differs from Scratch plus a chatbot, so that later implementation can be judged against the right model.

## US-069-05 - Implementation agent has stable invariants

As an implementation agent, I want clear source-of-truth rules for AI proposals, learner acceptance, visible code, runtime evidence and reflection, so that later architecture work does not reinterpret the product silently.
