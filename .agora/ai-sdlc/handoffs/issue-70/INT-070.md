# Product intent

## Business outcome

Create a durable learner competency progression and adaptive scaffolding rubric that turns the #69 AI-native learning loop into observable stages. The progression must show how learners move from block-first creation toward textual code, AI collaboration and AI literacy while preserving learner authorship.

## Users and stakeholders

Learners, curriculum designers, implementation agents, Product Owner and pedagogical reviewers. Later issues can use the rubric for curriculum metadata, tests and learning-companion behavior.

## Scope and non-goals

In scope: create `docs/product/LEARNING_PROGRESSION.md` covering programming, human-AI collaboration and AI literacy stages with observable learner behavior and scaffolding rules.

Out of scope: implementation code, UI components, provider/model selection, age-gating, a prompt-engineering course, or changing canonical program/runtime architecture.

## Success measures

The progression is concept-based, observable, provider-independent, covers programming plus AI literacy, reduces AI responsibility as autonomy increases, and defines over-assistance for each stage.

## Risks and dependencies

Depends on #69 docs after merge, #63 and `docs/architecture/PROGRAMMING_MODEL.md`. Main risks: hiding code behind staged UX, letting AI complete work before reasoning, or making understanding unobservable.
