# User Stories

## US-070-01 - Learner grows autonomy

As a learner, I want support to decrease as I understand more, so that AI does not keep doing the thinking for me.

## US-070-02 - Curriculum can observe understanding

As a curriculum author, I want each stage to name observable evidence, so missions can test understanding rather than just completion.

## US-070-03 - Learning companion avoids over-helping

As a product reviewer, I want clear over-assistance rules, so AI proposals remain scaffolding rather than hidden implementation.

## US-070-04 - Implementation agents inherit stable metadata

As an implementation agent, I want a rubric that can later drive curriculum metadata and tests without provider-specific behavior.
