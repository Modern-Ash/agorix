# Non-functional requirements

## NFR-070-01 - Observability

Every stage must name learner behavior that can be observed by product, runtime, curriculum or review.

## NFR-070-02 - Transparency

No stage may hide code or AI-originated work from the learner.

## NFR-070-03 - Provider independence

The rubric must work across local, open and commercial models.

## NFR-070-04 - Safety and privacy

AI literacy must state that private data is unnecessary for programming tasks and should not be requested.
