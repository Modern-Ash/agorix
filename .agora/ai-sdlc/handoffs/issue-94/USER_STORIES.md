# Issue 94 User Stories

## Local Gateway User

As a self-hosting user, I can point Agorix at a non-default OpenAI-compatible base URL and configured model without changing domain code.

## Protected Deployment User

As an operator of a protected compatible endpoint, I can provide auth configuration server-side while keeping browser surfaces free of secrets.

## Learner Safety Path

As a learner, malformed gateway output or unsupported capabilities cannot mutate my canonical program and instead produce explicit provider-runtime failures.

## Developer Path

As a developer, I can test the gateway adapter with local mocks and fixtures without calling an external service.
