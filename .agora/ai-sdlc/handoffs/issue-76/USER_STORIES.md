# User Stories - issue #76

- As a learner, I can press Step and see exactly one meaningful instruction highlighted before/with its visible result.
- As a learner, I can see the same instruction highlighted in the block workspace and textual code surface.
- As a learner, I can step through repeats and conditions in a way that explains entering, each body instruction, branch evaluation and completion.
- As a learner, I can stop, edit or reset without a hidden execution cursor continuing behind the scenes.
- As a tablet learner, I can use Step as a first-class touch control in narrow layouts.
- As a Studio user, I can inspect the same canonical step sequence as Web, even when Studio presents it with an inspector/table.
