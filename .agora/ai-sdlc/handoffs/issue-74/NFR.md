# Non-functional requirements - issue #74

- NFR1: Beginner-facing UX must avoid developer diagnostic overload.
- NFR2: Proposal, accepted code and runtime evidence must use distinct text/icon/provenance signals, not color only.
- NFR3: AI copy must avoid anthropomorphic certainty and must not claim behavior that runtime has not observed.
- NFR4: Accessibility requirements from `docs/product/UX_REQUIREMENTS.md` continue to apply.
- NFR5: Touch-first constraints from `docs/product/INTERACTION_MODEL.md` apply to tablet affordances.
- NFR6: Cross-surface semantics from `docs/product/CROSS_SURFACE_COMPATIBILITY.md` apply; presentation may differ, semantics may not.
- NFR7: Documentation must be source-controlled and implementable without private Figma/chat context.
