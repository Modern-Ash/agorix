1. semantic state machine;
2. program mutation paths;
3. AI proposal sequence;
4. execution controls and Step semantics;
5. code visibility per surface/viewport;
6. visual/provenance states;
7. Web/Tablet and Studio affordance mapping;
8. Playwright-testable assertions.
