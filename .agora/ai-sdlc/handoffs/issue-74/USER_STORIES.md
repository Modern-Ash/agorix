# User Stories - issue #74

- As a learner, I can see whether a change is only an AI suggestion or already part of my accepted program.
- As a learner, I can accept, modify or reject an AI suggestion before it changes my program.
- As a learner, I can keep code visible while editing blocks, reviewing AI suggestions, running, stepping, debugging and reflecting.
- As a learner, I can press Step and see which instruction is active and what changed.
- As a learner, I can stop or reset execution without losing my accepted program.
- As a learner using a tablet, I can understand proposal and evidence states through proposal cards, Action Palette and compact trace.
- As a learner using Studio, I can understand the same proposal and evidence semantics through diff review and Execution Inspector.
- As a developer, I can translate the contract into Playwright tests for #75-#78.
