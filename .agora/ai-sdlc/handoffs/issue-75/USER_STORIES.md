# User Stories - issue #75

- As a learner, I can review an AI suggestion before it changes my program.
- As a learner, I can reject a suggestion and know my accepted program did not change.
- As a learner, I can accept a suggestion only after seeing what will be added, changed or removed.
- As a learner, I can modify a suggestion and commit only the reviewed version.
- As a tablet learner, I can use touch-accessible Accept/Modify/Reject proposal actions.
- As a Studio learner, I can inspect the same proposal as a code/diff review.
- As a developer, I can test stale, invalid and malformed proposals without a provider.
- As a safety reviewer, I can confirm proposal audit records do not contain child PII or provider SDK details.
