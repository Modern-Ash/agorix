## Key concepts

- AI-native learner loop: intent, proposal, decision, runtime evidence, correction and explanation.
- Accepted program: learner-controlled canonical program state.
- Proposal: AI-originated suggestion that cannot mutate accepted state without learner decision.
- Runtime evidence: deterministic behavior that proves or refutes program claims.
- Legacy disposition: preserve, extend, supersede, defer or retire.
