# Issue 93 User Stories

## Local Learner Path

As a learner using Agorix in a local-first environment, I can receive documented Learning Companion help from a local Ollama model when the selected model is available and supports the configured capability.

## Parent Or School Setup Path

As an adult configuring Agorix for home or classroom use, I can choose an Ollama endpoint and model explicitly, understand hardware/model caveats, and avoid network provider credentials for the local path.

## Safety Path

As a learner, if a local model is unavailable, unsupported, too slow or returns malformed output, the editor/runtime remains usable and unsafe output cannot change my canonical program.

## Developer Path

As a developer, I can test the Ollama adapter deterministically without a local Ollama daemon, and optionally run a gated integration check when Ollama is available.
