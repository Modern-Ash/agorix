# User Stories - Issue #73

- US-001: As a user or school, I can see the repository's recognized OSS license immediately.
- US-002: As a contributor, I know how to propose a change, open a PR and satisfy review/check expectations.
- US-003: As a maintainer, I have a durable governance document for review authority and project decisions.
- US-004: As a provider/adapter author, I understand that model/provider licenses are separate from Agorix source licensing.
- US-005: As a curriculum/content contributor, I know prompts, policies and bundled assets must be license-compatible and auditable.
