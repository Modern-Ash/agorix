# Intent - Issue #73

## Objective

Make "open source" a repository fact by committing explicit license, contribution and governance artifacts.

## Source issue

GitHub #73: Formalize Agorix open-source license, governance and contribution model.

## Source facts

- Root `LICENSE`, `CONTRIBUTING.md` and `GOVERNANCE.md` are absent before this work.
- README already says Apache-2.0 is the preferred direction but warns not to claim formal Apache-2.0 status until the root license exists.
- #73 asks for a durable decision artifact.
- #63 and #67 require open-source-first, provider-neutral, auditable/community-extensible work.

## Proposed decision

Formalize Agorix source under Apache License 2.0, with Modern Ash as the copyright holder.
