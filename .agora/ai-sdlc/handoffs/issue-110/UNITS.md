## Proposed Units

### UOW-110-1: i18n foundation and governance docs

Define locale registry, message catalog structure, fallback policy, missing-key diagnostics, ADR, and contributor translation guide.

### UOW-110-2: Curriculum and mission localization

Localize First Mission, curriculum feedback, hints, prompts, and safety-critical learner copy in English and Spanish while keeping canonical mission identity stable.

### UOW-110-3: Web learner UI localization

Add locale selection and localize current app controls, proposal review, execution evidence, labels, statuses, and learner journey text.

### UOW-110-4: Learning Companion locale propagation

Make deterministic tutor responses locale-aware, propagate locale in provider context, and keep structured AI fields locale-independent.

### UOW-110-5: Verification, evidence, and docs equivalence

Add tests, screenshots or equivalent UI evidence, canonical hash/state comparison, README parity updates, and final verification evidence.
