# User Stories - Issue #72

## US-001 - Implementation agent

As an implementation agent, I want AGENTS.md to state explicit AI-native boundaries so that I cannot reasonably implement silent AI code edits.

## US-002 - Architecture reviewer

As an architecture reviewer, I want proposal, runtime, language and provider boundaries separated so that provider output cannot become domain authority.

## US-003 - Product owner

As Product Owner, I want old tutor terminology superseded or narrowed so that future work implements the learning companion loop from #69-#71.

## US-004 - Safety reviewer

As a safety reviewer, I want privacy and credentials boundaries encoded in the architecture so that child data and provider secrets do not leak into clients, logs or domain packages.
