## Intent interpretation

Issue #117 should define Agorix's reusable design system and modern visual language before the tablet-first shell, Worlds, touch model and Studio surface are implemented. The deliverable is a public, implementation-ready product/design source of truth, not a private mood board and not a React refactor.

The system must move Agorix away from its current POC/neo-brutalist look while preserving product invariants: code visibility, transparent AI proposals, deterministic runtime evidence, child agency, accessibility, multilingual support and cross-surface reuse between Web/Tablet and Studio.

## Scope boundaries

In scope: `docs/product/DESIGN_SYSTEM.md`, design tokens, semantic roles, component guidance, light/dark rules, accessibility guidance, EN/ES expansion guidance, and textual mockups/wireframes that can be reviewed in source control.

Out of scope for this issue: implementing a new React component library, redesigning the live app CSS, creating private Figma-only assets, or solving the full tablet shell (#118), touch model (#120), Worlds (#119), or Studio extension (#38).
