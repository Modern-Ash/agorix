## Non-functional Requirements

- NFR-001: Accessibility: token and component guidance must account for WCAG-aware contrast, visible focus, non-color-only state and reduced motion.
- NFR-002: Cross-surface consistency: tokens must be reusable across light Web/Tablet and dark Studio surfaces.
- NFR-003: Age range: visual language must avoid childish styling while remaining friendly for early learners.
- NFR-004: Maintainability: design decisions must live in repository docs and be implementable without private design context.
- NFR-005: Internationalization: component examples must allow EN/ES text expansion.
- NFR-006: Touch readiness: target sizes and spacing must support tablet-first follow-up work.
- NFR-007: Product integrity: visual emphasis must support code visibility, proposal boundaries and runtime evidence.
