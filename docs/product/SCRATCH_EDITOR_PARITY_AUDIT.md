# Escena libre: audit of familiar Scratch editor actions

Checked against the [Scratch editor help](https://scratch.mit.edu/help/studio/tips/home/), its [sprite and backdrop guide](https://scratch.mit.edu/help/studio/tips/howto/hoc-5/), and the current Kids Escena libre. The aim is a familiar place to make a project while retaining Agorix's learner-controlled Ori, synchronized code and runtime evidence. This is an interaction audit, not a claim of block-for-block compatibility.

| Learner action                             | Agorix today                                                                            | Gap or next decision                                                                                                                                                                     |
| ------------------------------------------ | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pick a block family and assemble a script  | Category rail, contextual palette, tap/drag, nested blocks, undo and redo               | The script surface needed more space and a visible drop area; this change enlarges it.                                                                                                   |
| Run and stop while watching the stage      | Jugar, Paso and Volver al inicio                                                        | The controls were buried below media tools; this change places them above the stage.                                                                                                     |
| Choose sprites and backdrops               | Gallery, drawing, image upload and placement                                            | The sprite list was visually indistinct; this change makes selection read as tiles. Backdrops still lack a thumbnail strip.                                                              |
| Edit the selected sprite                   | Position and layer controls; size, direction and visibility can be changed by blocks    | The inspector lacks direct rename, size, direction, show/hide, duplicate and delete actions. These need persistent actor metadata and model operations before exposing controls.         |
| Use costumes and sounds                    | Media tabs, custom raster costumes/backdrops, sound library and locally recorded sounds | Media is below the stage instead of adjacent to the script tabs. A unified Code / Costumes / Sounds workspace and costume thumbnails are still needed. Vector costume editing is absent. |
| Build several event scripts for one sprite | Green flag, click, key and message triggers, plus broadcast blocks                      | Escena libre has one script per actor; Scratch supports several independent scripts. This requires a program-model migration and explicit script selection.                              |
| Save and share a project                   | Local autosave, portable `.agorix` export/import; account flows exist separately        | No Scratch-like project title and public share/remix flow in Escena libre. Sharing needs product and child-safety design, not a cosmetic button.                                         |

Prioritize direct sprite management, a clear script switcher and nearby media tabs before adding more block families. Keep Ori contextual and optional; every AI idea remains a preview until the learner accepts it.
