# Competitive principles

Agorix does not clone another product. The POC combines proven interaction patterns while testing a distinct learning loop.

## Patterns to retain

### Scratch-like creative immediacy
- sprites/actors on a stage;
- event-driven visual scripts;
- immediate run/stop feedback;
- creative stories and games.

### MakeCode-like bridge to text
- visual blocks and textual representation express the same program;
- learners can reveal text progressively;
- textual mode is not a dead-end export.

### Tynker-like guided progression
- small missions;
- project-based learning;
- visible progress;
- free-play after structured guidance.

### Code.org-like AI assistance principle
- help should unblock learning;
- tutor context includes current task and current program;
- support should not remove the thinking step.

## Agorix decisions

1. Start with one polished creation loop, not a content catalog.
2. The canonical program model is independent from Blockly or any editor library.
3. Tutor intervention has levels: question → conceptual hint → structural hint → example → solution explanation.
4. Text view is initially read-only in the POC unless bidirectional editing proves inexpensive and safe.
5. No public sharing until child-safety and moderation are designed explicitly.
