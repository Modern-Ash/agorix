# Studio visual capability matrix

Issue #1652, under epic #1648. This matrix describes the Studio Workbench after the comparison-condition slice. The shared program and runtime support more nodes than the Workbench can currently create. A block appears in the palette only when Studio has an insertion path that reaches a canonical edit.

| Blocks                                                                                                                                                                                                           | Studio path                                                                                     | Remaining gap                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `event_green_flag`, `event_on_start`                                                                                                                                                                             | Existing script headers; a project opens with a start script                                    | Add and edit actor-scoped scripts and other hats                                                          |
| `event_broadcast`                                                                                                                                                                                                | Click or drag into a statement slot                                                             | Message target selection and receiver script creation                                                     |
| `motion_move`, `motion_turn`                                                                                                                                                                                     | Click or drag into a statement slot; edit number on block                                       | Full motion vocabulary and expression inputs                                                              |
| `looks_say`, `looks_think`, `looks_show`, `looks_hide`, `looks_set_size`, `looks_switch_costume`, `looks_switch_backdrop`                                                                                        | Click or drag; text and number fields are direct where present; choose assets in Scene          | Asset ID fields need visual pickers on the blocks                                                         |
| `sound_play`, `sound_stop`, `sound_set_volume`, `sound_change_volume`                                                                                                                                            | Click or drag; numeric volume fields are direct                                                 | Sound picker, import, playback preview                                                                    |
| `control_repeat`, `control_if`                                                                                                                                                                                   | Click or drag; nested statement slots; repeat count direct                                      | `repeat until`, richer nesting and keyboard indentation                                                   |
| `sensing_touching_goal`, `sensing_touching_actor`, `sensing_touching_stage_edge`, `literal_boolean`, `operator_less_than`, `operator_greater_than`, `operator_equals`                                            | Select in palette then click an `if` condition socket, or drag directly onto the socket         | Actor target selector, editable Boolean literal and nested expression operands                            |
| `motion_go_to`, `sensing_distance_to_actor`, `sensing_x_position`, `sensing_y_position`, remaining arithmetic/comparison/logical/random operators, `variables_*`, `lists_*`, `procedures_call`, other event hats | Canonical programs can contain many of these; unavailable for direct visual insertion in Studio | Typed expression sockets, declaration/selection UI, actor-scoped scripts and complete protocol projection |

| Asset or action                                 | Studio path                                                                | Remaining gap                                                      |
| ----------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Bundled and project PNG/WebP costumes/backdrops | Scene thumbnails; choose costume or backdrop; stage refreshes              | Import and draw in Studio, visual picker inside blocks             |
| Actors                                          | Scene cards and stage click selection; stage drag changes bounded position | Create/delete actor, script routing and richer direct manipulation |
| Run, Step, Stop, Reset                          | Workbench toolbar and deterministic stage/evidence                         | Cross-surface full-project journey gate                            |
| Ori suggestion                                  | Provisional review and explicit learner decision                           | Grounded conversational UI is a separate product contract          |

The first complete visual journey is: insert `if` → choose a sensing or comparison reporter → click or drop it into the condition socket → adjust numeric operands where present → Run/Step → inspect deterministic evidence. An invalid reporter, stale program hash, missing `if`, invalid operand, or rejected canonical program leaves accepted state unchanged.
