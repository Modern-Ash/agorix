# Product Intent — Agorix

## Vision

Agorix is a creative programming environment for children that combines the immediacy of block programming, the motivation of building games and stories, a progressive bridge to real textual code, and an AI tutor that teaches by hints instead of completing the work for the learner.

## Primary learner

POC target: children approximately 8–14 years old with no required previous programming experience.

The product must still be usable by an older beginner. Age must not be encoded as a hard technical limitation.

## Core job to be done

> I want to make something move, react and behave the way I imagined, and while doing it understand the programming idea that made it work.

## Product promise

A first-time learner can:

1. open a project;
2. see a stage and a character;
3. compose a small program visually;
4. run and stop it immediately;
5. observe the result;
6. change the program by experimentation;
7. ask for help when stuck;
8. receive a progressive hint rather than an automatic solution;
9. complete a challenge and understand the concept used.

## POC success moment

The learner completes the mission “reach the goal” using an event plus movement/control blocks, runs the project, encounters at least one failure or incomplete attempt, uses a hint, corrects the program and completes the mission.

## Differentiators to validate

- One canonical program can be viewed as blocks and as readable text.
- The transition to text is gradual, not a separate course.
- AI support is pedagogically constrained.
- Challenges teach concepts through creation rather than lectures.
- Free-play remains available after guided work.

## Non-goals for POC

- public social network;
- classroom administration;
- payments/subscriptions;
- native mobile apps;
- multiplayer;
- hardware/robotics integration;
- full curriculum;
- production-scale moderation;
- arbitrary user code execution on a server.
