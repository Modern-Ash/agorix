## How to work here

- One branch and one worktree per issue: `git worktree add -b <branch> ../.agorix-agora-worktrees/<name> origin/main`, then `corepack pnpm install --frozen-lockfile`.
- Checks that CI runs: `corepack pnpm format:check`, `pnpm lint`, `pnpm test`, `pnpm build`, `pnpm security:check`; web e2e: `cd apps/web && corepack pnpm build && corepack pnpm exec playwright test <spec>`.
- Open a PR linked to the issue; **do not self-merge** (the owner merges). Update `CHANGELOG.md` (Unreleased) for user-visible changes.
- Every new engine capability needs: model type and validator, deterministic runtime and trace, projections (Agorix Code, Python, Java, TypeScript), block and Studio control, `STUDIO_BLOCK_CATEGORY` entry, coverage-guard update, unit tests, fresh-session e2e.

## Gotchas

- `tsconfig` excludes `*.test.ts`, so tests are not type-checked. Put compile-time guards in normal modules (see `kidsCreationCoverage.ts`); prove a guard bites by mutating it.
- Accessible names must be unique: a duplicate button name broke two Studio e2e specs. Run `e2e/kids-studio.spec.ts` and `a11y.spec.ts` after UI changes.
- Studio validates strictly (`validateStudioProgram`): step multiples, closed value lists, depth limits. Sample programs in tests must respect them.
- `playwright --repeat-each` leaks dev-backend state in `kids-adult-link`; run such specs once.
- `browser-smoke` in CI had two timing flakes on unrelated PRs (`accounts.spec.ts:285`, `kids-adult-link.spec.ts:174`); rerun the failed job before suspecting the change.
- A worktree was moved to the system Trash once mid-session; do not remove worktrees of open branches. A PR merged before its last commit was pushed lost that commit, so push everything before asking for the merge.
- Persistence metadata changes follow the `kidsView`/`sceneGoal` pattern (store.ts, portable.ts key list and builder, compatibility.ts three places, index.ts export, test).
